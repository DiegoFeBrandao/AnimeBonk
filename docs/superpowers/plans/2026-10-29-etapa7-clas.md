# Etapa 7 — Clãs (v1 enxuta) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.

**Goal:** Fundar clã (custa Essência; nome + sigla de até 4 letras + emblema de peças),
entrar (aberta / por pedido / convite), cargos (leader / officer / member), pontos de clã
somados pelas partidas dos membros, ranking de clãs e telas no Menu (Find clan, My clan,
Clan ranking, Inbox). Missões semanais, rivalidade e mural ficam pra uma 2ª fase.

**Architecture:** Dados em DataStore próprio `"Clas"` (chave = clanId, valor `Cla = {
versao, id, nome, sigla, emblema: { forma, simbolo, cor }, descricao, lider: userId,
oficiais: {userId}, membros: {userId} (≤ `ClaVagasBase` 30, ampliável a 100 com Essência),
entrada: "aberta"|"pedido"|"convite", pedidos: {userId}, pontos: number, criadoEm }`),
índice por nome em `"ClasPorNome"`, pedidos/convites do jogador no perfil (`perfil.cla =
{ id: string?, convites: {claId}, pedidosFeitos: {claId} }`, schema **v5**), ranking em
`OrderedDataStore("PontosCla")`. `ClaSystem` (Menu: tudo; Partida: só `somarPontos` no fim
da partida via `UpdateAsync` no clã do jogador). Toda escrita em clã usa `UpdateAsync`
(várias pessoas mexem no mesmo registro); nomes/sigla/descrição passam por
`TextService:FilterStringAsync` (obrigatório). Remotes `Cla*` validados com rate-limit
(fundar 10 s, demais 1 s). Sigla aparece antes do nome no ranking e no painel de perfil.

**Spec:** §16; referência de layout `docs/pokebonk-referencia.md` §16 (só estrutura).

## Review Focus
1. Duas fundações com o mesmo nome ao mesmo tempo → só uma vence (`UpdateAsync` no índice por nome).
2. Líder sai/é o último → clã dissolvido ou liderança passa pro oficial mais antigo; membro removido perde `perfil.cla.id`.
3. Texto não filtrado nunca é gravado/exibido; falha do filtro = recusa.
4. Pontos só do servidor; partida de quem sai no meio não soma; membro removido não soma mais.
5. Limites: vagas, 1 clã por jogador, sigla 2–4 letras A–Z, nome 3–20 chars, Essência nunca negativa.

### Task 1: Shared v5 (Types.Cla/Perfil.cla, Logica/Perfil migrar, Logica/Cla (validações puras, cálculo de pontos), Definicoes/Emblemas, Config) nos 2 places + TesteLogica.
### Task 2 (Menu): ClaSystem completo (fundar, buscar, pedir, aceitar/recusar, convidar, sair, expulsar, promover, ampliar vagas, mudar entrada) + ClaRankingSystem (leitura top 10 com cache).
### Task 3 (Partida): somar pontos no `terminar` (abates/10 + guardiões×20 + vitória 100); sigla no HUD/nome.
### Task 4 (Menu): telas Find clan / My clan / Clan ranking / Inbox + fundação com editor de emblema.
### Task 5: teste em Play nos 2 places + revisão + docs.
